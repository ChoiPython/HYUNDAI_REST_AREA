# 쉼자리 기획 요약

## 고객의 불편과 제안

운전자와 동승자는 정차한 차량에서 잠깐 쉬거나 차박을 할 때 공조, 소리와 알림을 따로 설정하고 휴식 후 되돌려야 합니다. 쉼자리는 개인별 선호를 기억해 환경 준비, 기상 시간 예약과 휴식 평가를 연결합니다.

첫 버전은 정차 중 휴식을 중심으로 구현합니다. 이동 중 동승자 모드, 차박의 에너지 관리, 좌석 이동과 도착 연동은 지원 API와 사용 환경을 확인하며 확장합니다.

## 사용 흐름

1. 별명으로 프로필을 선택하고 사용할 좌석을 정합니다.
2. 온도, 풍량, 소리와 휴식 시간을 선택합니다.
3. 차량 지원 정보와 적용할 항목을 확인합니다.
4. P단·정차 여부를 확인한 뒤 지원되는 공조 설정만 적용하거나, 타이머만 시작합니다.
5. 휴식 시간 종료 또는 수동 종료 시 변경한 설정을 복원하고 편안함을 기록합니다.
6. 다음 휴식에서 동일한 설정을 불러오거나 피드백에 맞춰 조정합니다.

## 차량에서 제공하는 가치

프로필과 좌석별 공조 지원 범위, 정차 상태와 설정 복원을 한 흐름에 연결합니다. 공용 공조와 스피커가 다른 탑승자에게 영향을 줄 수 있음을 시작 전에 안내합니다. 차량 서비스가 없는 환경에서는 체험 모드임을 표시합니다.

## 검증과 초기 사업 가정

초기 대상은 장거리 이동 중 정차 휴식을 자주 하는 운전자와 차량에서 쉬는 성인 동승자입니다. 동일 사용자의 기존 설정 방식과 앱 사용을 교차 비교해 준비 시간, 조작 횟수, 편안함과 재사용 의향을 측정할 계획입니다.

- 설정 조작 횟수 50% 감소: 검증할 목표이며 달성 실적이 아닙니다.
- 출시 후 3개월 베타 설치 500명, 월 활성화 60%를 가정한 예상 MAU 300명.
- 첫 사용 후 30일 이내 재사용률 30% 목표. 현재 측정된 지표가 아닙니다.
- 핵심 기능 무료 제공을 우선 검토하고, 사용성 검증 후 복수 상황 루틴과 차량 서비스 연계를 검토합니다.
- Pleos App Market 입점은 별도 심사 대상으로, 입점·배포를 보장하지 않습니다.

휴식 기록은 주관적 편안함과 환경 설정의 기록입니다. 습도 제어, 수면 단계 측정, 의학적 수면 개선 또는 운전 재개 가능 판정은 제공하지 않습니다.
