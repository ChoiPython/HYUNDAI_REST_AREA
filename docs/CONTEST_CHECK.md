## 개발 범위와 확인 수준

| 항목 | 확인 결과 |
| --- | --- |
| 개발 환경 | minSdk 28, Gradle 8.9, Java 17. 공식 API 28 이상·Gradle 8 이상·Java/Kotlin 기준 충족. |
| 공개 SDK | Vehicle 2.3.2와 NaviHelper 3.0.5는 공식 문서의 버전과 일치한다. HVAC capability/get/set, 읽기 전용 ETA 어댑터를 사용한다. |
| 권한 | 공조 조회·제어, Navi 경로 정보 조회에 맞는 권한을 선언했다. 경로 변경·음성 인식·통화 내용 수집 권한은 사용하지 않는다. |
| 비공개 기능 | 미공개 LLM SDK, 외부 차량 마이크 전송, 직접 CAN/하드웨어 제어는 포함하지 않는다. 좌석 자동 이동·습도 유지도 구현 성공으로 기재하지 않는다. |
| 주행 제한 | 자동차 화면에서 CarUxRestrictions를 조회·구독하고 제한 시 상세 UI를 숨긴다. 동승자 선택으로 이를 해제하지 않는다. 운전자 휴식은 주차 확인 후 시작한다. |
| 오디오 | 표준 MediaBrowserService·MediaSession과 오디오 포커스 처리, 명시적 재생, 개인 종료 알림을 구현했다. 차량 미디어 호스트·핸들 키·Gleo 실동작은 미검증이다. |
| 오류·오프라인 | 네트워크 실패와 체험 값을 실제 성공으로 표시하지 않는다. 마지막 개인 기상 예약·로컬 설정을 유지한다. 재부팅·권한·절전 조건은 README에 설명한다. |
| 현재 검증 | 53개 단위 테스트·Lint 오류 0. UI·재생·TLS 양쪽 역할·예약 알림의 에뮬레이터 검증 범위는 VERIFICATION.md에 있다. |
| 남은 검증 | 현재 최종 버전의 Pleos 에뮬레이터 두 APK 연속 연결, 실제 활성 경로 ETA, 공조 쓰기/재조회/복원의 성공은 확인하지 못했다. 기존 실행을 최종 연속 시험 통과로 간주하지 않는다. |
| 라이선스 | 점검 중 일반 배포 라이브러리의 원문 고지 누락을 발견해 THIRD_PARTY_NOTICES.txt를 저장소와 APK assets에 추가했다. 글꼴 OFL·외부 데이터 출처도 제공한다. |

2차 심사는 **Pleos Connect 에뮬레이터 시연** 기준이며 실제 차량이 필수는 아니다. 따라서 남은 우선 과제는 실차 확보가 아니라 최종 버전의 안정적인 Pleos 에뮬레이터 시연이다. 최초 접수 산출물은 2차 PT 전까지 고도화할 수 있다. 이 제한은 현재 제출 가능한 1차 프로토타입과 구분한다.

## 마켓 출시와 참가자 확인 사항

공식 공지는 공모전 심사가 Pleos App Market 입점 심사가 아니라고 명시한다. 현재 결과물에 대해 마켓 전체 정책 준수·입점 가능을 확인했다고 주장하지 않는다. 휴식 서비스의 마켓 카테고리와 음악 부기능의 분류는 별도 검토해야 한다. 음악을 주 기능으로 하지 않는 앱을 Music/Audio로 등록하지 않으며, `android:appCategory="audio"`를 선언해 주행 제한을 우회하지 않는다. 향후 입점에는 카테고리·미디어 호스트/하드키·Gleo·권한 승인·세부 UI/접근성/성능 검증이 남아 있다.

순수 창작 여부, 다른 공모전의 기수상작 여부, 현대자동차그룹 임직원 여부와 기재 정보의 사실성은 소스·파일만으로 확정할 수 없으며 참가자가 확인해야 한다. 제3자 SDK와 데이터는 원저작자의 조건을 따른다. 수상 후 현장 참석·전시 APK 제출과 권리 관련 협의 조건도 참가자가 확인해야 한다.
