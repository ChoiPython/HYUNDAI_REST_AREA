# 동승자 휴식과 운전자 휴식

쉼자리의 출발점은 달리는 차 안에서 동승자가 느끼는 편안함이다. 1.2는 이 경험을 기본 모드로 두고, 운전자의 정차 휴식을 별도 모드로 제공한다. 주행 중인 운전자는 휴식 대상이 아니다.

## 두 모드의 실제 차이

| 항목 | 동승자 휴식 | 운전자 휴식 |
| --- | --- | --- |
| 선택 좌석 | 동승석·뒷좌석 왼쪽·오른쪽 | 운전석 |
| 시작 조건 | 정차 여부와 독립적으로 음악·타이머 시작 | 확인된 P단·정차 필요. 상태 불명일 때는 사용자가 실제 주차를 확인하고 공조 없이 타이머 사용 |
| 배경 음악 | 명시적 시작 후 mediaPlayback foreground service로 유지 | 앱 화면을 벗어나면 중지 |
| 차량 화면 | 화면 켜짐·밝기를 강제로 바꾸지 않음. 화면을 벗어나도 음악 유지 | 어두운 휴식 화면·타이머 제공 |
| 종료 안내 | 조용한 알림 채널. 차량 스피커로 기상음을 강제 재생하지 않음 | 기상 알림과 기상 화면 |
| 공조 | 출발 전 선택적으로 준비. 주행 중 자동 쓰기 없음 | 정차·지원·권한 확인 후 온도·풍량 요청 |
| 기록 | 동승자 모드·좌석·시간·느낌 저장 | 운전자 모드·시간·느낌 저장 |

기존 프로필에 모드 값이 없으면 운전석은 운전자 휴식으로, 다른 좌석은 동승자 휴식으로 복구한다. 진행 중인 세션은 시작 당시의 모드·좌석·음악 목록을 별도 복사해 유지한다. 재실행 시 타이머는 복구하되 프로세스 재생성만으로 음악을 자동 재생하지 않는다.

동승자 휴식의 기본 시작은 공조 조회에 의존하지 않는다. 차량 API가 없어도 동승자 음악과 타이머를 시작할 수 있다. 출발 전 공조 준비를 따로 선택하면 기존 P단·정차 가드와 좌석 영역·허용 범위 검증을 적용한다. 주행 중 복원 요청 역시 가드로 차단되며 현재 차량 설정을 유지하고 결과를 알린다.

## 주행 중 화면과 음악

역할 선택과 차량의 화면 사용 허용은 별개다. `CarUxRestrictionsManager`의 현재 상태와 변경 콜백을 사용하며 제한된 디스플레이에서는 상세 설정·음악 검색·프로필 편집 화면을 표시하지 않는다. DO 메타데이터로 사용자 역할을 가장하거나 플랫폼 제한을 해제하지 않는다. 운전자 휴식 중 제한이 발생하면 해당 타이머와 음악을 중지하고 주차 후 마무리하도록 안내한다.

동승자 음악은 화면이 숨겨져도 지속할 수 있는 오디오 서비스이며 재생 알림과 표준 MediaSession을 제공한다. 표준 MediaBrowserService는 음악 폴더와 선택한 곡 목록을 공개한다. 연결만으로 재생하지 않고 실제 시작·재생 요청에만 응답한다. 음악이 끝나거나 중지·일시정지·오류가 발생하면 FGS를 종료하고 재생 자원을 해제한다. 안내나 통화로 인한 일시 중단은 최대 30초를 기다린 뒤 해제한다.

이 구조는 실제 차량의 모든 승객 화면 지원, 주행 UI 허용, 미디어 호스트 연동 또는 앱 마켓 승인을 보장하지 않는다. 음악이 보조 기능인 앱을 음악 카테고리로 간주해 배포할 수 있다고 가정하지 않으며 실제 주 기능과 심사 기준에 맞게 확인해야 한다. 현재 차량 제어 성공의 미검증 범위는 [검증 기록](VERIFICATION.md)을 따른다.

## 다음 개발 우선순위

1. **도착 전 깨우기**: 도착 예상 시각과 준비 여유 시간을 연결한다. 우선 직접 입력으로 사용성을 검증하고, 내비게이션의 공식 목적지·ETA 연동 범위와 동의를 확보한 뒤 자동화한다. 현재 타이머는 직접 정한 휴식 시간이다.
2. **동승자 휴대전화 연결**: 센터 디스플레이를 만지지 않고 자신의 좌석·기분·음악 선호를 설정하는 동반 앱 흐름을 검증한다. 동일 APK의 휴대전화 실행과 차량 간 페어링은 다른 기능이며, 현재 페어링·원격 제어는 구현하지 않았다.
3. **여러 동승자의 선호 조정**: 좌석별 온도와 공용 풍량·음악을 구분해 동시에 쉬는 사람들의 요구가 충돌할 때 조정한다. 현재는 여러 프로필을 저장하지만 휴식 세션은 한 번에 하나다. 실제 차량의 독립 공조 영역과 스피커 분리 지원이 전제다.
4. **피드백을 반영한 다음 휴식**: 현재의 추웠음·더웠음·소리·자세 평가를 바탕으로 다음 설정을 제안한다. 자동으로 변경하기 전에 사용자가 확인한다. 주관적 편안함과 준비 조작 횟수로 검증하며 수면 단계나 의학적 효능으로 표현하지 않는다.
