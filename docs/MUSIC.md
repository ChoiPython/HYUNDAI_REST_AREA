# 상황에 맞는 휴식 음악

1.1.0은 사용자가 선택한 휴식 목적·현재 기분·선호 장르와 날씨·시간을 참고해 실제 곡을 추천하고 재생한다. 추천 서비스는 공개 검색·스트리밍이 가능한 Audius다. 멜론의 믹스업 API나 사용자의 멜론 라이브러리에 연결한 기능은 아니다.

## 추천 과정

1. 사용자가 잠깐 잠들기·조용히 쉬기·기분 전환을 고른다.
2. 현재 기분을 선택하거나 비워둔다. 최근 통화 후의 느낌도 사용자가 직접 고른다.
3. 날씨를 직접 선택하거나, 도시를 선택해 Open-Meteo 모델 예보를 가져온다. 조회 시각과 출처를 표시한다. 실패하면 직접 선택을 안내한다.
4. 명시적 장르 선호를 먼저 적용하고, 목적·선택한 기분·시간·날씨로 기본 장르와 원하는 음악 무드 태그를 정한다. 날씨만으로 사용자의 감정을 판정하지 않는다.
5. Audius에서 해당 장르·무드의 공개 곡을 최대 50개 조회하고, 장르·무드 일치와 제공된 BPM의 근접도를 비교한다. 곡의 공개 태그·제목에 날씨·시간·직접 고른 기분과 관련된 단어가 있으면 보조 점수를 준다. 최대 5개를 제안하며 조건이 너무 좁으면 같은 장르에서 무드 필터를 풀어 검색한다.
6. 곡명·아티스트·장르·무드·길이·추천 이유를 표시한다. 사용자가 고른 곡부터 목록을 순환하며 재생한다.

추천은 규칙 기반이다. 새로운 AI 모델을 학습시키거나 수면 개선 효과를 판정하지 않는다. 무드와 BPM은 서비스가 제공한 메타데이터이며 태그만으로 음악의 실제 음량·가사 유무·편안함을 보장하지 않는다.

## 실제 API와 접근 제한

- 음악 검색: `https://api.audius.co/v1/tracks/search`, `genre`, `mood`, `sort_method`, `limit`, `includePurchaseable`.
- 스트리밍: `https://api.audius.co/v1/tracks/{id}/stream?app_name=Shimjari`.
- `is_streamable=true`, `is_stream_gated=false`, `access.stream=true`, 별도 `stream_conditions` 없음이 확인된 곡만 목록에 넣는다. ID·길이·필수 메타데이터도 검증한다.
- 결제·가입·서명·API 키 등 추가 조건을 우회하지 않는다. 이후 접근 조건이 바뀌어 재생이 실패하면 오류로 표시한다.
- 날씨: `https://api.open-meteo.com/v1/forecast`. 선택한 도시의 공개 좌표와 `current=temperature_2m,weather_code`를 사용한다. GPS·실시간 위치 추적은 사용하지 않는다.
- 검색 응답은 10분, 도시 예보는 15분 캐시한다. 연결·읽기 제한 시간과 응답 크기 상한을 두고 실패 시 가짜 결과를 만들지 않는다.

음악 원본은 저장소·APK에 넣지 않는다. 앱에서 스트리밍하며 아티스트와 Audius 출처·원본 곡 링크를 표시한다. 날씨는 Open-Meteo 모델 자료를 한국어 분류로 변환한 것이며 출처와 CC BY 4.0을 안내한다. 서비스 이용 조건은 상용 배포 전에 다시 확인해야 한다.

## 재생과 휴식 세션

`MediaPlayer`로 비동기 재생하고 `MediaSession`으로 곡 정보와 제어 상태를 제공한다. 음악 일시정지·처음부터 다시 재생·다음 곡·이전 곡을 지원한다. 1.2부터 동승자 모드는 사용자가 시작한 음악을 mediaPlayback foreground service에서 배경 재생하며, 운전자 모드는 앱을 벗어나면 음악을 중지한다. 두 모드 모두 세션 종료 시 음악을 멈춘다. 오디오 포커스에 따라 음량 감소·일시정지·중지를 처리하며 포커스가 완전히 사라졌을 때 반복적으로 빼앗아 오지 않는다. 일시정지·오류·완전한 포커스 상실 후에는 서비스와 자원을 해제한다.

표준 `MediaBrowserService`가 선택한 동승자 세션의 음악 폴더와 공개 곡 목록을 제공하고 동일한 `MediaSession`에 연결한다. 브라우저 연결만으로 세션이나 재생을 시작하지 않는다. 실제 Pleos 미디어 호스트 노출·스티어링 휠 키·Gleo 음성 제어·앱 마켓 배포 승인을 보장하는 구현 완료 주장은 하지 않는다. 앱의 주 기능에 맞는 카테고리와 출시 심사를 별도로 확인해야 한다.

휴식 종료 30초 전부터 해당 플레이어의 음량만 줄인다. 차량 전체 볼륨이나 안전 안내 음량은 변경하지 않는다. 선택한 음악 목록은 프로필과 세션에 복사해 저장한다. 재생 위치와 현재 곡 순서는 복구 대상이 아니다. 프로세스 재생성 후에는 사용자가 다시 재생을 눌러야 하며 첫 곡부터 시작할 수 있다.

기분 선택 자체와 통화 내용은 외부로 전송하지 않는다. 요청하는 것은 음악의 장르·무드 태그 또는 도시 좌표다. 외부 서비스에는 IP 주소 등 통신 정보가 전달될 수 있다. 통화·마이크·연락처 권한을 추가하지 않았으며 로그인·음악 계정 토큰도 사용하지 않는다.

## 기존 서비스와의 관계

멜론은 이미 Pleos 앱 마켓에 입점해 개인화 추천과 플레이리스트를 제공한다. 음악 추천과 차량 공조 각각을 새 기능으로 주장하기보다는 이동 중 동승자 휴식과 주차 후 운전자 휴식을 구분하고 음악 선택·환경 준비·종료 안내·복원·평가를 연결하는 사용 흐름에 집중한다. [현대차그룹의 앱 마켓 발표](https://hyundaimotorgroup.co.kr/ko/news/42dot-pleos-connect-app-market-new-apps).

또한 2026년 8월 사내 해커톤에서 ‘아기 꿀잠 드라이브’가 수상했다. 해당 발표만으로 상세 기능이나 현재 앱 마켓 출시 여부를 확인할 수는 없다. 수면·휴식이라는 주제 자체의 독창성을 단정하지 않는다. [현대차그룹의 해커톤 발표](https://www.hyundaimotorgroup.com/ko/news/hyundai-motor-company-kia-24h-code-race-hackathon).

## 1.3 동승자 음악 제어

차량이 지정한 음악 대표만 승인된 휴대폰에서 선택 목록을 전송하고 재생·일시정지·다음 곡·중지를 요청할 수 있다. 다른 운전자/동승자 휴식의 음악을 덮어쓰지 않는다. 역할과 기상 예약은 [연결 안내](COMPANION.md)를 따른다.
